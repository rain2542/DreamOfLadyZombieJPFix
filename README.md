# Dream of Lady Zombie JP Fix

『屍姫の夢 / Dream of Lady Zombie』の非公式日本語翻訳MODです。

## 概要

ゲーム内テキストの未翻訳・誤訳・不自然な表現を修正し、日本語で遊びやすくすることを目的としています。

## 導入について

MelonLoaderを使用して導入します。

詳しい導入手順は後ほど追記します。

## 既知の問題

- 一部UIで日本語フォントが正しく表示されず、文字が「□」になる場合があります。
- ゲーム本体の更新により動作しなくなる可能性があります。

## 注意

このMODは非公式です。
ゲーム開発元・販売元とは関係ありません。
